# Predictive Forecasting of Care Load and Placement Demand

## Project Overview

This project focuses on analysing healthcare care transitions, predicting patient care workload, and forecasting placement demand using data analytics and predictive techniques.

The project aims to support better resource planning, discharge efficiency, and placement decision-making through data-driven insights.

## Objectives

- Analyse patient care transition patterns.
- Understand care workload and discharge trends.
- Forecast future care load and placement demand.
- Identify patterns in placement outcomes.
- Present analytical insights through an interactive dashboard.

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Data Analytics
- Predictive Forecasting

## Dashboard Features

- Care transition analytics
- Discharge efficiency analysis
- Placement outcome analysis
- Data visualisation
- Predictive forecasting (planned / in development)

## Project Purpose

This project demonstrates the application of data analytics to healthcare resource planning and care transition management.
